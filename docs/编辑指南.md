# 标题、简介与关键词修改指南

## 1. 仓库首页的大标题

位置：仓库根目录 `README.md` 第一行，以 `#` 开头。

当前标题：

```text
USDT支付系统开发｜支付订单、到账通知与商户对账
```

在 GitHub 打开 README.md，点击铅笔图标编辑，完成后提交改动即可。README 中“开发与定制方向”“常见问题”“相关关键词”和“联系方式”也可以一起修改。

## 2. 仓库名称

当前仓库：`haohao866/-usdt-otc-`。

名称在仓库 Settings → General → Repository name 中修改。改名后请同步修改 README 的克隆地址和进入目录的命令。

## 3. 仓库右侧 About 简介

位置：仓库首页右侧 About 旁边的齿轮。

建议 Description：

```text
USDT支付系统开发演示｜支付接口集成、订单管理、到账通知、商户对账与定制开发。当前公开代码为本地模拟示例。
```

About 简介是 GitHub 的仓库设置，不会因为修改 README 自动更新。

## 4. 可点击的 Topics 标签

位置：同一个 About 编辑窗口里的 Topics 输入框。可按相关性选用：

```text
usdt
usdt-payment
usdt-payment-system
payment-system
payment-gateway
stablecoin-payments
merchant-payments
payment-integration
payment-orders
payment-notification
reconciliation
payment-demo
```

标签使用小写英文和连字符。中文业务词自然写入 README 的标题、介绍和相关关键词，不需要反复复制堆叠。只选择与你实际内容或清楚标明的开发方向相关的词。

## 5. 联系方式与搜索收录

联系方式在 README 的“联系方式”段落。当前为你指定的 Telegram 链接。

公开 README 中的账号、链接、代码和图片都有被搜索引擎或第三方抓取的可能。GitHub README 无法对其中一个 TG 账号单独设置不收录，写入 HTML 的 nofollow 也不等于禁止索引。若不能接受被搜索到，请在发布前移除公开联系方式；删除后历史提交和缓存也可能保留旧内容。

若日后使用自己控制的独立联系页面，可单独配置 noindex，但这不提供保密保证，也不会控制 GitHub 提交历史中的旧内容。

## 6. 如何增加内容

优先补充真实的接口说明、示例输出、运行步骤、截图和可交付功能。新增尚未实现的内容时，放在需求方向或计划中，并说明状态。当前示例没有真实到账通知、链上监听、U卡发卡或OTC交易功能。
